# Typography Studio

Typography Studio turns the selected rendered text into a source-accountable typography workspace.

1. Select a text layer on Canvas, then open **Typography studio** from the workspace menu, command palette, or `0` shortcut.
2. Use **Project** to review fonts already active or declared in the product. Choosing one creates a normal reviewed font-family change.
3. Use **Google** to preview the live catalog. Before review, choose the project-appropriate integration strategy. Foundry records the exact family, weight, style, source actions, and verification plan as evidence.
4. Use **Local** to preview fonts installed on the device when the browser supports local font access. Local fonts are never written to source without an explicit project asset or integration decision.
5. Use the live specimen, rendered metrics, diagnostics, and project usage map to judge the change in context. Do not treat the specimen alone as proof that the rebuilt product is correct.
6. Type treatments and modular or fluid scale values are temporary until added to review. Reset restores the original inline values without creating a change.
7. Saved project styles are local design memory. Applying one still creates exact reviewed property changes; saving a style does not silently create source tokens.
8. During apply, preserve the project-native font system, aliases, loading strategy, and framework conventions. Verify the rebuilt family, weight, style, axes, size, line height, tracking, wrapping, clipping, and load status across every recorded viewport, theme, and state.

Do not claim that a local preview is portable. Do not add a Google or self-hosted font without its recorded source plan. Do not hide overflow or clipping by changing the viewport.
