# Security

Foundry runs locally, binds its runtime to the loopback interface, and protects each design session with a generated token. Keep session URLs and exported change sets private because they may contain local paths and design details.

## Report a vulnerability

Please use GitHub's private vulnerability reporting for sensitive issues. Do not open a public issue containing an exploit, session token, private source, or local filesystem details.

For ordinary bugs without sensitive information, open a GitHub issue with the Foundry version, operating system, framework, and a minimal reproduction.

Supported security fixes currently target the latest beta release.
