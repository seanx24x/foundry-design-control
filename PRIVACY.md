# Privacy

Foundry is local-first. It does not require an account, use a Foundry cloud service, include telemetry, or send analytics.

Foundry processes rendered element measurements, design changes, local project paths, source mappings, validation results, and apply-run history on your machine. Session data is stored locally so work can be reviewed, resumed, exported, and verified.

The coding agent, package registry, source host, and browser you choose have their own privacy practices. Foundry does not control those services. Review an exported change set before sharing it because it can include local paths and source locations.

Use `foundry-design uninstall` in a project to remove Foundry's project integration. Local session data can also be deleted from Foundry's application-support directory when it is no longer needed.
